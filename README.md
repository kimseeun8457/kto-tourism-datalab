# Holiday Boost

## 핵심 질문
공휴일은 평시와 비교해 지역 관광수요를 얼마나 변화시키며, 연휴 유형(단일/주말연계/
징검다리/장기연휴)에 따라 어느 지역이 특히 강하게 반응하는가?

## 프로젝트 성격
- 2026 한국관광 데이터랩 활용 경진대회 출품작
- **범위**: 연휴 유형별 관광수요 반응 차이 규명 + 유형별 맞춤 정책 제안
  (잠재지역 발굴 단계는 범위에서 제외 — 분석 단순화를 위해 축소)
-  참가구분: 개인 (1인 작업 중, 상황에 따라 1~2인 팀 전환 가능)
- 분석기간: 2024~2025년 (2개년)

## 분석 파이프라인

| STEP | 내용 |
|---|---|
| 0 | 데이터 가용성 검증 (API 스펙 확인 완료) |
| 1 | 공휴일+주말 캘린더 구축 및 유형화 (순수주말형/단일휴일형/주말연계형/징검다리형/장기연휴형) |
| 2 | 인스턴스 단위 Holiday Lift 계산 (연도별로 분리, 동일요일 ±4주 로컬 기준선 사용) |
| 3 | 전국(대상지역) 유형별 Holiday Lift 비교 |
| 4 | (시간 여유 시) 지역 유형화 — 관광핵심형/휴일특수형/일상관광형/저반응형 4분면 분류 |
| 5 | 연휴 유형별 지역 반응 차이 분석 및 정책 제안 |

## 핵심 지표: Holiday Lift
Holiday Lift = 공휴일(연휴) 방문객 수 ÷ 평시 기준 방문객 수

- 평시 기준선은 **동일 요일 ±4주** 데이터로 설정 (요일 효과 통제)
- 각 공휴일 인스턴스는 **연도별로 독립 계산** 후 평균/표준편차로 반복성 검증
  (연도 간 날짜·요일 직접 매칭은 하지 않음)
- 기준선 계산 시 다른 공휴일과 겹치는 날짜는 표본에서 제외

## 사용 데이터 (공공데이터포털 API)

| API | 용도 | 시간단위 |
|---|---|---|
| 한국관광공사_빅데이터_지역별 방문자수 | 핵심 지표 (Holiday Lift 계산) | 일별 |
| 한국관광공사_지역별 관광 수요 강도 | 성공요인 보조분석 (소비) | 월별 |
| 한국관광공사_지역별 관광 자원 수요 | 성공요인 보조분석 (검색) | 월별 |
| 한국관광공사_지역별 관광 다양성 | 보조 근거 (연령/국적) | 월별 |
| 한국천문연구원_특일정보 | 공휴일 캘린더 구축 | 월별 조회 |

> 방문자수는 **외지인**(touDivCd=2)만 사용 — 현지인의 일상 이동과 관광수요를
> 구분하기 위함. 소비/검색 3종 API는 월 단위 집계라, 특정 공휴일 당일 효과가
> 아닌 "공휴일이 낀 달의 경향성" 정도의 보조 근거로만 활용.

## 폴더 구조

```
holiday-boost/
├── data/
│   ├── raw/          # API로 받은 원본 데이터 (git 추적 안 함)
│   └── processed/    # 전처리된 중간 산출물 (git 추적 안 함)
├── notebooks/        # 단계별 분석 노트북
├── src/              # API 클라이언트, Holiday Lift 계산 함수 등
├── outputs/
│   ├── figures/      # 그래프
│   └── tables/       # 최종 결과표
└── docs/             # 의사결정 로그, 노션 문서 백업
```
